# Русификация Online Office на UGREEN NAS (UGOS Pro)

> ## ⚠️ Важно: проект в разработке
>
> - Проект **находится в разработке** и не является официальным. Он **никак не связан с UGREEN**.
> - Скрипты изменяют системные файлы UGOS Pro (оболочку и Online Office) **с правами root**. После обновления прошивки или приложений они могут перестать работать или привести к сбоям интерфейса.
> - **Никаких гарантий стабильной работы нет.** Используйте на свой страх и риск: вся ответственность за последствия лежит на вас.
> - Перед установкой сделайте резервную копию важных данных и настроек. Откат: `--revert` (см. ниже), но он тоже не гарантирован.
> - Переводы выполнены автоматически, возможны неточности и строки, оставшиеся на английском.

Online Office на UGREEN NAS — это обёртка над OnlyOffice. Русская локализация в OnlyOffice есть, но на системах без русского языка недоступна: интерфейс остаётся английским, а **регион и язык формул** в редакторе таблиц всегда `English`.

Этот набор скриптов включает русский интерфейс и задаёт русские значения по умолчанию для региона, языка формул и языка словаря. После установки:

- интерфейс обёртки Online Office и редакторов на русском;
- формулы пишутся по-русски (`СУММ`, `МИН`, `МАКС`), регион «Русский – Россия» (`1 000,01 ₽`, `04.10.2026`);
- язык словаря проверки орфографии русский;
- после обновления Office всё применяется заново автоматически (если включён автозапуск).

## Две команды: только Office или вся система

| Что | Установить | Откатить |
|---|---|---|
| Только Online Office | `sudo bash install.sh` | `sudo bash install.sh --revert` |
| Вся система (оболочка + Office) | `sudo bash russify.sh` | `sudo bash russify.sh --revert` |

Скачать скрипты:

```
curl -fsSL -o install.sh https://raw.githubusercontent.com/VasilCreat/ugos-office-russify/main/install.sh
curl -fsSL -o russify.sh https://raw.githubusercontent.com/VasilCreat/ugos-office-russify/main/russify.sh
```

- `install.sh` русифицирует только Online Office (регион, язык формул, словарь). Свой таймер автоприменения.
- `russify.sh` русифицирует оболочку UGOS (рабочий стол, Панель управления, Файлы, Хранилище, Docker и др.) и Office, ставит один таймер автоприменения после обновлений и снимает старый таймер Office. Строки без перевода остаются английскими.
- Параметры обоих: `--no-autorun` (без таймера), `--remove-autorun` (убрать таймер), `--revert` (откат и удаление таймера).
- После запуска обновите страницу в браузере (Ctrl+F5).

**Нюансы**

- `russify.sh --revert` откатывает и оболочку, и Office. Чтобы откатить только Office, оставив оболочку русской, используйте `install.sh --revert`.
- После отката в папках перевода остаются пустые файлы `ru-RU.json`: если в браузере был запомнен русский язык, окна приложений откроются на английском, а не белыми. Если всё же видите белые окна, очистите данные сайта или удалите ключ `LANG` в Local Storage (F12 → Application).
- Установка добавляет «Русский» в выпадающий список языков (Панель управления → Время и язык): строка `[ru-RU]` в `/ugreen/language/.language.ini` и `ru-RU` в `languageList` в `config.json` приложений. Откат убирает оба изменения. Сообщения самой системы (серверные), для которых перевода нет, остаются английскими.
- Если запускать оба скрипта по очереди, останется один общий таймер от `russify.sh` (он снимает старый таймер Office).
- GitHub кэширует ветку `main` на несколько минут. Если после обновления репозитория скрипт скачал старую версию, укажите в ссылке хэш коммита вместо `main`, а для переводов задайте `RUSSIFY_RAW`:
  ```
  curl -fsSL -o russify.sh https://raw.githubusercontent.com/VasilCreat/ugos-office-russify/<хэш-коммита>/russify.sh
  sudo RUSSIFY_RAW=https://raw.githubusercontent.com/VasilCreat/ugos-office-russify/<хэш-коммита> bash russify.sh
  ```
- Таймер проверяет файлы раз в 30 минут. После обновления прошивки русификация вернётся не мгновенно; если интерфейс остался английским, запустите скрипт ещё раз.
- Проверить таймер: `systemctl list-timers ugos-russify.timer`, журнал: `journalctl -u ugos-russify.service -n 50`.

## Установка

1. Установите **Online Office** из Центра приложений UGOS.
2. Подключитесь к NAS по SSH и выполните одну команду.

   Если репозиторий публичный, ничего копировать не нужно:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/VasilCreat/ugos-office-russify/main/install.sh | sudo bash
   ```
   Либо скачайте `install.sh`, положите на NAS и запустите:
   ```bash
   sudo bash install.sh
   ```
3. В браузере на странице документа нажмите `Ctrl+Shift+R`, создайте **новую** таблицу и проверьте: Файл → Параметры → Региональные параметры, затем `=СУММ(`.

Если не помогло, очистите данные сайта для адреса NAS (`F12` → Application → Storage → Clear site data). В приложении UGREEN NAS на Mac дополнительно удалите кэш:

```bash
rm -rf "$HOME/Library/UGREEN_Nas_Pro/.cache/office/"
rm -rf "$HOME/Library/Application Support/com.ugreen.desktop/Cache/Cache_Data/"
```

## Автозапуск после обновлений

Включается сам при установке, отдельных действий не нужно. Скрипт сохраняет свою копию в `/volume1/ugos-russify/` (на томе с данными, а не в домашней папке) и создаёт systemd-таймер `ugos-office-russify.timer`. Раз в 30 минут `install.sh --auto` сверяет «отпечаток» файлов Office. Если они не менялись, ничего не происходит и сервис не перезапускается. Если Office обновился, русификация применяется один раз.

```bash
systemctl list-timers ugos-office-russify.timer      # таймер на месте?
journalctl -u ugos-office-russify.service -n 50       # журнал
sudo bash /volume1/ugos-russify/install.sh --remove-autorun   # убрать автозапуск
sudo bash install.sh --no-autorun                      # установить без автозапуска
```

После обновления **прошивки** проверьте, что таймер остался. Если его нет, просто запустите установку ещё раз.

## Что именно патчится

Пути относительно `/volume1/@appstore/com.ugreen.office`.

| Шаг | Файл | Что меняется |
| --- | --- | --- |
| 1 | `www/locale/ru-RU.json(.gz)` | создаётся перевод интерфейса обёртки |
| 2 | `www/locale/en-US.json(.gz)` | переименовывается в `.bak` |
| 3 | `www/assets/ugos-framework-*.js` | язык по умолчанию и сообщение родительскому окну → `ru-RU` |
| 4 | `config.json` | `ru-RU` добавляется в `languageList` |
| 5 | `onlyoffice/.../api/documents/api.js` | язык редактора в адресе: `lang=ru-RU` |
| 6 | `onlyoffice/.../spreadsheeteditor/main/app.js`, `ie/app.js` | регион `ru-ru`, язык формул и словаря `ru-RU` по умолчанию |
| 7 | — | перезапуск `office_serv` |

Бэкапы лежат рядом с файлами (`*.bak`, для `app.js` — `app.js.ruorig`).

### Почему одного `lang=ru` мало

- В `api.js` нужен полный код `ru-RU`, а не `ru`: при коротком коде интерфейс русский, но регион не выводится.
- Но и этого недостаточно. Редактор берёт регион из `editorConfig.region`, а при его отсутствии — из `editorConfig.lang`, который присылает бэкенд `office_serv`, и у UGOS он английский. Поэтому в шаге 6 задаются значения по умолчанию.
- Значения по умолчанию действуют, только пока пользователь не выбрал свои в настройках редактора: сохранённый в браузере выбор имеет приоритет.

## Ограничения

- Проверено на UGOS Pro (UGREEN DXP4800PLUS) с Online Office, у которого в имени файла `ugos-framework-*.js` меняется хэш. Скрипт ищет файл по маске.
- Патчи правят минифицированный JS по точным шаблонам. После обновления Office шаблоны могут измениться: тогда скрипт напишет «ВНИМАНИЕ … шаблон не найден» и не применит этот патч. В таком случае нужен новый шаблон.
- Предупреждение шага 3 «fallback-переменная не найдена» известно и не критично, пока язык браузера русский.
- Старые xlsx хранят собственные региональные настройки, проверять лучше на новой таблице.
- Не затронуты: язык самой системы UGOS, веб-панель NAS, Docker-версия Office.
- Скрипты меняют файлы приложения и перезапускают `office_serv`. Используйте на свой риск и держите бэкапы.
