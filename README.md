# Русификация Online Office на UGREEN NAS (UGOS Pro)

Online Office на UGREEN NAS — это обёртка над OnlyOffice. Русская локализация в OnlyOffice есть, но на системах без русского языка недоступна: интерфейс остаётся английским, а **регион и язык формул** в редакторе таблиц всегда `English`.

Этот набор скриптов включает русский интерфейс и задаёт русские значения по умолчанию для региона, языка формул и языка словаря. После установки:

- интерфейс обёртки Online Office и редакторов на русском;
- формулы пишутся по-русски (`СУММ`, `МИН`, `МАКС`), регион «Русский – Россия» (`1 000,01 ₽`, `04.10.2026`);
- язык словаря проверки орфографии русский;
- после обновления Office всё применяется заново автоматически (если включён автозапуск).

## Файлы

| Файл | Назначение |
| --- | --- |
| `install.sh` | Применяет русификацию. Идемпотентен, можно запускать повторно. |
| `setup-autorun.sh` | Ставит systemd-таймер, который сам запускает `install.sh --auto` после обновлений. |

## Установка

1. Установите **Online Office** из Центра приложений UGOS.
2. Положите `install.sh` и `setup-autorun.sh` в одну папку на NAS и выполните по SSH:
   ```bash
   sudo bash install.sh 2>&1 | tee /tmp/install_log.txt
   ```
3. В браузере на странице документа нажмите `Ctrl+Shift+R`, создайте **новую** таблицу и проверьте: Файл → Параметры → Региональные параметры, затем `=СУММ(`.

Если не помогло, очистите данные сайта для адреса NAS (`F12` → Application → Storage → Clear site data). В приложении UGREEN NAS на Mac дополнительно удалите кэш:

```bash
rm -rf "$HOME/Library/UGREEN_Nas_Pro/.cache/office/"
rm -rf "$HOME/Library/Application Support/com.ugreen.desktop/Cache/Cache_Data/"
```

## Автозапуск после обновлений

```bash
sudo bash setup-autorun.sh
```

Скрипт копирует `install.sh` в `/volume1/ugos-russify/` и создаёт systemd-таймер `ugos-office-russify.timer`: раз в 30 минут `install.sh --auto` сверяет «отпечаток» файлов Office. Если они не менялись — ничего не происходит, сервис не перезапускается. Если Office обновился — патчи применяются один раз.

```bash
systemctl list-timers ugos-office-russify.timer     # таймер на месте?
journalctl -u ugos-office-russify.service -n 50      # журнал
sudo bash setup-autorun.sh --remove                  # убрать автозапуск
```

После обновления **прошивки** проверьте, что таймер остался. Если нет — `sudo bash /volume1/ugos-russify/setup-autorun.sh`.

## Что именно патчится

Пути относительно `/volume1/@appstore/com.ugreen.office`.

| Шаг | Файл | Что меняется |
| --- | --- | --- |
| 1 | `www/locale/ru-RU.json(.gz)` | создаётся перевод интерфейса обёртки |
| 2 | `www/locale/en-US.json(.gz)` | переименовывается в `.bak` |
| 3 | `www/assets/ugos-framework-*.js` | язык по умолчанию и сообщение родительскому окну → `ru-RU` |
| 4 | `config.json` | `ru-RU` добавляется в `languageList` |
| 5 | `onlyoffice/.../api/documents/api.js` | язык редактора в адресе: `lang=ru-RU` |
| 6 | `onlyoffice/.../spreadsheeteditor/main/app.js`, `ie/app.js` | регион `ru-ru`, язык формул и словаря `ru-RU` по умолчанию |
| 7 | — | перезапуск `office_serv` |

Бэкапы лежат рядом с файлами (`*.bak`, для `app.js` — `app.js.ruorig`).

### Почему одного `lang=ru` мало

- В `api.js` нужен полный код `ru-RU`, а не `ru`: при коротком коде интерфейс русский, но регион не выводится.
- Но и этого недостаточно. Редактор берёт регион из `editorConfig.region`, а при его отсутствии — из `editorConfig.lang`, который присылает бэкенд `office_serv`, и у UGOS он английский. Поэтому в шаге 6 задаются значения по умолчанию.
- Значения по умолчанию действуют, только пока пользователь не выбрал свои в настройках редактора: сохранённый в браузере выбор имеет приоритет.

## Ограничения

- Проверено на UGOS Pro (UGREEN DXP4800PLUS) с Online Office, у которого в имени файла `ugos-framework-*.js` меняется хэш. Скрипт ищет файл по маске.
- Патчи правят минифицированный JS по точным шаблонам. После обновления Office шаблоны могут измениться: тогда скрипт напишет «ВНИМАНИЕ … шаблон не найден» и не применит этот патч. В таком случае нужен новый шаблон.
- Предупреждение шага 3 «fallback-переменная не найдена» известно и не критично, пока язык браузера русский.
- Старые xlsx хранят собственные региональные настройки, проверять лучше на новой таблице.
- Не затронуты: язык самой системы UGOS, веб-панель NAS, Docker-версия Office.
- Скрипты меняют файлы приложения и перезапускают `office_serv`. Используйте на свой риск и держите бэкапы.
