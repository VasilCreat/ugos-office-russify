# Где в UGOS Pro лежат языки (и что меняет русификация)

Схема составлена по файлам реального NAS (UGOS Pro 1.21). Принцип проекта: **русский добавляется как ещё один язык системы, а язык выбирает сама система.** Английские файлы не заменяются и не прячутся.

## Откуда берётся язык пользователя

| Что | Где | Кто пишет |
|---|---|---|
| Выбранный язык пользователя | `/ugreen/.config/.nas/<uid>/ugos.lang` (одно слово, напр. `de-DE`) | служба UGOS при «Применить» в «Личные → Язык и форматы» |
| Язык в браузере | `localStorage["LANG"]` | оболочка (`ugos-framework`) |
| Язык Office | параметр `lang=` в адресе `…/office/openfile?…&lang=…` | `office_serv` по языку пользователя |
| Язык websocket-соединений | параметр `lang=` в адресе `wss://…/ws?…&lang=…` | оболочка |

## Список языков, который видит пользователь

| Что | Где | Что делает русификация |
|---|---|---|
| Названия языков в выпадающем списке | `/ugreen/language/.language.ini` (секции `[ru-RU] name=Русский enable=true`) | добавляет секцию `[ru-RU]`, откат убирает |
| Языки, поддерживаемые приложением | `<app>/config.json` → `languageList` | дописывает `ru-RU` приложениям, где есть `en-US` |
| Названия и описания приложений (подписи иконок) | `<app>/config.json` → `i18n` (запись на каждый `langName`) | добавляет запись `ru-RU` (переводы в `ru/apps-i18n.json`) |
| Сообщения службы (ошибки, уведомления) | `/ugreen/language/*.csv` (колонки по языкам: `zh-CN,en-US,de-DE,…`) | пока не трогаем: колонки `ru-RU` там нет |

## Переводы интерфейса

| Что | Где | Что делает русификация |
|---|---|---|
| Строки окна приложения | `<app>/www/**/locale/<язык>.json` (+ `.gz`) | кладёт `ru-RU.json` рядом с `en-US.json` |
| Окно без перевода | то же | кладёт пустой `{}` как `ru-RU.json`: без файла дочерние окна при языке `ru-RU` получают 404 и открываются пустыми |
| Язык по умолчанию | `locale/en-US.json` | **не трогаем** (оболочка всегда загружает его как запасной) |
| Выбор языка в коде | `www/**/ugos-framework-*.js` → `switchLang(...)` | по умолчанию не трогаем; только по `RUSSIFY_FORCE=1` подставляем `ru-RU` для пустого/`en-US` |

## Online Office (OnlyOffice)

| Что | Где | Что делает русификация |
|---|---|---|
| Строки обёртки | `com.ugreen.office/www/locale/ru-RU.json` | создаёт |
| Язык редактора | `…/web-apps/apps/api/documents/api.js` (`params += "&lang=…"`) | берёт язык из `?lang=` адреса страницы, иначе `editorConfig.lang` |
| Язык формул и словаря таблиц | `…/spreadsheeteditor/main/app.js`, `ie/app.js` (`appOptions.lang`) | берёт язык из `?lang=` iframe |
| Регион (даты, числа) | там же | не трогаем (редактор выводит его из языка) |

## Откат и проверка

- `sudo bash russify.sh --revert` убирает: секцию `[ru-RU]`, `ru-RU` из `languageList` и `i18n`, наши правки в `ugos-framework`, `api.js`, `app.js`, таймеры. Переводы `ru-RU.json` заменяются пустыми заглушками.
- `sudo bash check-clean.sh` (только чтение) показывает, что ещё осталось, и ловит старые следы: русский текст в `en-US.json`, `.bak`/`.ruorig`, жёсткие подмены из ранних версий.
- Если следы остались, надёжный способ вернуть оригинал: переустановить приложение из Центра приложений (для Office) или обновить прошивку.
